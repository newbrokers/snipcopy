SnipCopy for Windows

1. Extract this zip.
2. Install the .NET 8 Desktop Runtime if Windows asks for it.
3. Run SnipCopy.exe.
4. Use Ctrl+Shift+S to take a snip, Ctrl+Shift+R to select a recording area, or double-click the tray icon.
5. Open Settings from the tray or the editor Settings tab to activate a SavedCode Pro license.

SnipCopy verifies its SavedCode Pro license offline after activation.
Licenses and the customer portal are available at savedcode.com.
