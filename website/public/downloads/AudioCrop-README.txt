Audio Crop for Windows
======================

Audio Crop is a SavedCode desktop utility for trimming audio into clean MP3 clips.

How to run:
1. Extract this zip to a folder.
2. Run AudioCrop.exe.
3. Open an audio file.
4. Play or seek to set start and end times.
5. Add one or more segments, then export.

Supported input:
- MP3
- WAV
- FLAC
- OGG
- M4A
- AAC

Requirement:
- Windows 10 or newer
- .NET 8 Desktop Runtime

Required audio tools:
Audio Crop uses FFmpeg tools for duration, preview, and export.

Install them with:
winget install Gyan.FFmpeg

Or place ffmpeg.exe, ffprobe.exe, and ffplay.exe beside AudioCrop.exe.

Free:

- Create segments
- Export up to 3 segments
